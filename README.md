# Boston Housing Data Analysis

## Project Overview
This project analyses housing data using Microsoft Excel to understand the relationship between housing factors and average house prices.

## Project Objectives
- Explore and understand the housing dataset.
- Calculate descriptive statistics.
- Perform correlation analysis.
- Apply simple and multiple linear regression.

- Identify patterns related to housing prices.

## Tools Used
- Microsoft Excel
- Descriptive Statistics
- Correlation Analysis
- Regression Analysis

## Analysis Performed
1. Data exploration
2. Descriptive statistical analysis
3. Correlation analysis
4. Simple linear regression
5. Multiple linear regression
